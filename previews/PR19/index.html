PowerOpenAPIModels

Julia transport types for the Sienna power-system data model, generated from SiennaSchemas.

These packages are the wire format, not the data model. They describe what a Sienna system looks like as JSON — every component, every association row, every unit annotation — with no dependency on PowerSystems.jl or InfrastructureSystems.jl. That is what lets a parser, a database, a service, or a language other than Julia exchange a system with Sienna without linking against Sienna itself.

Pre-release

Every version below 1.0 is a pre-release. These packages can change incompatibly in any release, and no API stability is promised until 1.0. Julia treats a bump in x of 0.x.y as breaking, so a [compat] entry of "0.1" resolves within 0.1.* — pin accordingly.

The seven packages

Seven packages live in one repository, each registered separately so an application loads only what it needs. The dependency chain is acyclic and each package owns one layer.

PackageOwnsDepends on
InfrastructureCoreOpenAPIModelsDomain-neutral types, the model-type registry, the unit vocabulary, the APIModel supertypes—
InfrastructureTimeSeriesOpenAPIModelsThe six time series association typesInfrastructureCore
PowerCoreOpenAPIModelsPower types shared across domains: topology, curves, costs, enumsInfrastructureCore
PowerOperationsOpenAPIModelsBranches, injections, services, outages, market structuresPowerCore
PowerInvestmentsOpenAPIModelsTechnologies, financial data, policy requirementsPowerCore
PowerDynamicsOpenAPIModelsDynamic machine, exciter, governor, and inverter modelsPowerCore
PowerOpenAPIModelsRe-exports all six, plus SystemDocument and PortfolioDocumentall

The two Infrastructure* packages must never gain a Power* dependency; the test suites enforce it.

Installation

using Pkg

# Everything, plus the document containers
Pkg.add("PowerOpenAPIModels")

# Or one domain only
Pkg.add("PowerOperationsOpenAPIModels")

A first example

using PowerOpenAPIModels, JSON

bus = ACBus(;
    id = 1,
    number = 1,
    name = "bus1",
    available = true,
    bustype = ACBusType("REF"),
    base_voltage = 138.0,
    voltage_limits = MinMax(; min = 0.95, max = 1.05),
)

text = JSON.json(encode(bus))
"{\"id\":1,\"number\":1,\"name\":\"bus1\",\"available\":true,\"bustype\":\"REF\",\"voltage_limits\":{\"max\":1.05,\"min\":0.95},\"base_voltage\":138.0}"
back = decode(ACBus, JSON.parse(text))
back.voltage_limits
MinMax(1.05, 0.95, Dict{String, Any}())

The API describes the whole surface: how a generated type is shaped, how encoding and decoding work, how enums and discriminated unions are represented, how units are declared, and how a whole document is assembled and validated.

Regenerating

The Julia sources under each package's src/ are generated by OpenAPI.jl's native Julia generator from the SiennaSchemas bundles. A fix belongs in the schema or in the generator configuration, never in the generated file — see the repository README.
