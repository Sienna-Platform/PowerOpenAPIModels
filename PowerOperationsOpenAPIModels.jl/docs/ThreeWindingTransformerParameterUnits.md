# ThreeWindingTransformerParameterUnits

Unit basis for the pairwise measured impedance fields (r_12, x_12, r_23, x_23, r_31, x_31). PSS/E supplies a single CZ flag for the whole three-winding transformer record, so one basis governs all three winding pairs.

## Allowed values
- `NATURAL_UNITS`
- `COMPONENT_BASE`
