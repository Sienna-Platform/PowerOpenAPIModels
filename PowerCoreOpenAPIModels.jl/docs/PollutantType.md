# PollutantType

Pollutant an emission rate is reported for, spanning greenhouse gases (`CO2`, `CO2E`, `CH4`, `N2O`), criteria pollutants (`NOX`, `SO2`, `CO`, `VOC`, `PM25`, `PM10`), and toxics (`HG`, `HAP`), with `CUSTOM` for a user-defined pollutant.

## Allowed values
- `CO2`
- `CO2E`
- `CH4`
- `N2O`
- `NOX`
- `SO2`
- `CO`
- `VOC`
- `PM25`
- `PM10`
- `HG`
- `HAP`
- `CUSTOM`
