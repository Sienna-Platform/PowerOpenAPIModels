PowerDynamicsOpenAPIModels.ActiveConstantPowerLoad — Type
ActiveConstantPowerLoad

Parameters of 12-states active power load based on the paper, "Dynamic Stability of a Microgrid With an Active Load." It has no bus of its own: exactly one static injection device, with the same name, names it in its dynamic_injector property, and that device supplies the rest of its data.

  • id: Unique integer identifier for this component.
  • name: Name of the dynamic injection. Must equal the name of the static injection device that names it in dynamic_injector.
  • r_load: DC-side resistor
  • c_dc: DC-side capacitor
  • rf: Converter side filter resistance
  • lf: Converter side filter inductance
  • cf: AC Converter filter capacitance
  • rg: Network side filter resistance
  • lg: Network side filter inductance
  • kp_pll: Proportional constant for PI-PLL block
  • ki_pll: Integral constant for PI-PLL block
  • kpv: Proportional constant for Voltage Control block
  • kiv: Integral constant for Voltage Control block
  • kpc: Proportional constant for Current Control block
  • kic: Integral constant for Current Control block
  • p_ref: Reference active power (pu). Units: pu.
  • q_ref: Reference reactive power (pu). Units: pu.
  • v_ref: Reference voltage (pu). Units: pu.
  • frequency_ref: Reference frequency, in natural units. Usually equal to the system frequency. Units: Hz.
  • is_filter_differential: Boolean to decide if filter states are differential or algebraic
  • base_power: Base power for the per-unit parameters of this model. Usually equal to the base_power of the static injection device that names this model. Units: MVA.

DynamicGenerator

Dynamic response model of a synchronous generator. It names five function blocks by id: a synchronous machine model, a shaft, an excitation system, a turbine governor, and a power system stabilizer. It has no bus of its own: exactly one static injection device, with the same name, names it in its dynamic_injector property, and that device supplies the rest of the generator's data.

  • synchronous_machine_dynamics: ID of the SynchronousMachineDynamics function block: the machine model for the electromagnetic dynamics.
  • shaft: ID of the Shaft function block: the shaft model for the electromechanical dynamics.
  • excitation_system_dynamics: ID of the ExcitationSystemDynamics function block: the excitation system model.
  • turbine_governor_dynamics: ID of the TurbineGovernorDynamics function block: the prime mover and turbine governor model.
  • power_system_stabilizer_dynamics: ID of the PowerSystemStabilizerDynamics function block: the power system stabilizer model.
  • base_power: Base power for the per-unit parameters of the referenced function blocks. Usually equal to the base_power of the static injection device that names this model. Units: MVA.

PowerDynamicsOpenAPIModels.DynamicInverter — Type
DynamicInverter

Dynamic response model of a grid-connected inverter. It names its function blocks by id: a converter, an active and a reactive power control, an inner control, a DC source, a reference frame rotation (the frequency estimator), a filter, and an optional current limitation. It has no bus of its own: exactly one static injection device, with the same name, names it in its dynamic_injector property, and that device supplies the rest of the inverter's data.

  • id: Unique integer identifier for this component.
  • name: Name of the dynamic injection. Must equal the name of the static injection device that names it in dynamic_injector.
  • frequency_ref: Frequency reference set-point, in natural units. Usually equal to the system frequency. Units: Hz.
  • converter: ID of the Converter function block: the converter model.
  • active_power_control: ID of the ActivePowerControl function block: the outer active power control.
  • reactive_power_control: ID of the ReactivePowerControl function block: the outer reactive power control.
  • inner_control: ID of the InnerControl function block: the inner control model.
  • dc_source: ID of the DCSource function block: the DC source model.
  • reference_frame_rotation: ID of the ReferenceFrameRotation function block: the frequency estimator (PLL) model.
  • filter: ID of the Filter function block: the output filter model.
  • current_limitation: ID of the CurrentLimitation function block: the output current limiter model, or null when the inverter has no limiter.
  • base_power: Base power for the per-unit parameters of the referenced function blocks. Usually equal to the base_power of the static injection device that names this model. Units: MVA.
